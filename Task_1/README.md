## 🔍 Data Cleaning Process

### 1. Dataset Import

The dataset is imported using Pandas:

```python
df = pd.read_csv("dataset.csv")
```

### 2. Dataset Inspection

The script examines:

* Complete dataset
* First five records
* Dataset shape
* Column names
* Data types
* Dataset information

### 3. Missing Value Detection

Missing values are identified using:

```python
df.isnull().sum()
```

### 4. Duplicate Detection

Duplicate records are identified using:

```python
df.duplicated().sum()
```

The duplicate rows are also displayed for inspection.

### 5. Removing Duplicate Records

Duplicate records are removed using:

```python
df = df.drop_duplicates()
```

### 6. Handling Missing Values

Missing values are handled using appropriate statistical and categorical methods:

* **Age** → Median
* **Gender** → Mode
* **Department** → Mode
* **Salary** → Median

### 7. Correcting Inconsistent Values

Inconsistent gender values such as `male`, `M`, `female`, and `F` are standardized into:

* `Male`
* `Female`

Department values are also cleaned by removing unnecessary spaces, standardizing capitalization, and correcting values such as `It` and `Hr`.

### 8. Data Type Conversion

The Salary column is converted into a numeric data type using:

```python
df["Salary"] = pd.to_numeric(df["Salary"], errors="coerce")
```

### 9. Final Data Validation

After cleaning, the script checks:

* Remaining missing values
* Remaining duplicate records
* Final data types
* First five cleaned records

### 10. Exporting the Cleaned Dataset

The final cleaned dataset is saved as:

```text
cleaned_dataset.csv
```

using:

```python
df.to_csv("cleaned_dataset.csv", index=False)
```
