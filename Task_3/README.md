# 📊 Customer Data Analysis — CODSOFT Task 3

## 📌 Project Overview

This project was completed as **Task 3 of the CODSOFT Internship**.

The objective of this project is to analyze customer information to understand **purchasing behavior, customer segments, spending patterns, and high-value customer groups**.

The analysis was performed using **Python, Pandas, and Matplotlib**, with the results presented through visual reports and actionable marketing strategies.

---

## 🎯 Objectives

The main objectives of this project are:

* Analyze customer purchasing behavior
* Segment customers based on **age**
* Segment customers based on **location**
* Analyze customers based on **buying patterns**
* Identify the most valuable customer groups
* Create visual reports to communicate customer insights
* Suggest marketing strategies based on the analysis

## 📊 Dataset

The dataset contains **1,000 customer records** and **13 columns**.

### Dataset Columns

| Column               | Description                          |
| -------------------- | ------------------------------------ |
| `Customer_ID`        | Unique customer identifier           |
| `Age`                | Customer age                         |
| `Gender`             | Customer gender                      |
| `Location`           | Customer city/location               |
| `Customer_Type`      | New or Returning customer            |
| `Total_Orders`       | Total number of orders               |
| `Total_Spend`        | Total amount spent by customer       |
| `Avg_Order_Value`    | Average value of an order            |
| `Product_Category`   | Product category purchased           |
| `Purchase_Frequency` | Low, Medium, High, or Very High      |
| `Discount_Used`      | Whether the customer used a discount |
| `Customer_Rating`    | Customer rating                      |
| `Age_Group`          | Customer age segment                 |

## 🔍 Analysis Performed

### 1. Purchasing Behavior Analysis

The project analyzes:

* Total customers
* Total orders
* Total customer spending
* Average order value
* Product category distribution
* New vs Returning customers
* Purchase frequency

### 2. Age Segmentation

Customers are divided into:

* 18–25
* 26–35
* 36–45
* 46–55
* 56–65

The spending behavior of each age group is compared.

### 3. Location Segmentation

Customer spending is analyzed across different locations to identify areas with higher customer spending.

### 4. Buying Pattern Segmentation

Customers are segmented according to purchase frequency:

* Low
* Medium
* High
* Very High

Total and average spending are compared across these groups.

### 5. Valuable Customer Groups

The project identifies high-value groups based on:

* Total spending
* Product category
* Location
* Age group
* Customer type
* Purchase frequency
